# Phase 1 — ItemReading foundation + PET pilot

Status: planned, not implemented. See PR description for the full implementation brief.

Part of the "domain-specific trip log + statistics for every item type" initiative — see
`wrenchly-architecture.md` / project memory for the broader context. This phase builds the
`ItemReading` engine (a generic "log a number over time" model + registry-driven UI) and wires it
up fully for one pilot domain (PET, weight tracking) to prove the pattern before rolling it out to
the other nine `ItemReading` domains in Phase 2.
